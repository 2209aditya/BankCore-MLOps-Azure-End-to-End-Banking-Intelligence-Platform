Automation

CI/CD — Azure DevOps pipeline

From developer push to production blue/green deployment — fully automated with champion vs challenger model evaluation and manual approval gates.

1
Developer push to feature branch
Code pushed to Azure Repos triggers CI automatically. Runs flake8, black, isort, mypy, and pytest across unit and integration test suites.
2
Docker build + push to ACR
FastAPI inference image built and pushed to Azure Container Registry. AML environment registered with updated dependencies and version hash.
3
AML training pipeline triggered (on merge to main)
Challenger model trained on latest curated dataset. Metrics logged to MLflow — AUC, F1, KS statistic, Gini coefficient, and fairness scores.
4
Champion vs challenger evaluation
Challenger compared against production champion. Promotion blocked if challenger fails to exceed champion AUC threshold or fails fairness and bias checks.
5
Staging deployment + smoke tests
Challenger deployed to AKS staging namespace. Smoke tests fire synthetic transactions and verify prediction latency, schema correctness, and edge case handling.
6
Manual approval gate → production blue/green
ML lead approves promotion in Azure DevOps. Blue/green swap on AKS production with instant rollback capability. Model registered in AML Registry with full lineage.

Setup

Getting started

Prerequisites: Python 3.11+, Azure CLI with ML extension, Docker, kubectl, and Make.

01
Clone and configure
Clone the repo and copy the environment template.
git clone https://dev.azure.com/your-org/bankcore-mlops/_git/bankcore-mlops cd bankcore-mlops cp .env.example .env
02
Provision Azure infrastructure
Deploy all Azure resources via Bicep — AML Workspace, ADLS Gen2, ACR, AKS, Key Vault, App Insights, Azure OpenAI.
az login az deployment group create \ --resource-group rg-bankcore-dev \ --template-file infra/main.bicep \ --parameters infra/parameters/dev.parameters.json
03
Submit a training job
Train the fraud detection model on the AML compute cluster.
az ml job create \ --file src/pipelines/fraud_training_pipeline.yml \ --workspace-name aml-bankcore-dev \ --resource-group rg-bankcore-dev
04
Deploy to AKS
Get AKS credentials and apply Kubernetes manifests.
az aks get-credentials --resource-group rg-bankcore-dev --name aks-bankcore-dev kubectl apply -f k8s/deployment.yaml kubectl apply -f k8s/service.yaml kubectl apply -f k8s/hpa.yaml kubectl get pods -n bankcore
